# 学习通课程顺序播放助手

当前版本：**0.4.9**。本项目是适用于 Edge 和 Chrome 的本地浏览器扩展。

## 产品介绍

助手从当前章节开始，按课程页面顺序处理视频和 PDF 文档，并根据平台显示的任务点状态进入下一项。视频优先尝试 2 倍速，不允许时使用原速；文档会滚动可访问的阅读区域，并等待平台确认完成。助手不会拖动视频进度或自行发送学习记录。

章节测验可选择自动跳过、遇到时暂停、使用模型填写后手动确认，或使用模型填写并自动提交。视频中途出现的单选题或多选题会逐组尝试；无法继续时暂停，提示使用者处理。模型答题支持 DeepSeek 官方 API 和自定义 OpenAI 兼容接口。

扩展在本机运行，使用者自行通过学习通 APP 扫码登录。设置页支持导出和清理本机诊断日志。

## 使用方式

### 第一次安装

1. 如果下载的是压缩包，先解压。在解压后的文件夹中找到 `extension` 文件夹。
2. 打开 Edge，在顶部地址栏输入 `edge://extensions` 并按回车；使用 Chrome 时输入 `chrome://extensions`。
3. 打开页面上的“开发人员模式”，点击“加载解压缩的扩展”，选择刚才找到的 `extension` 文件夹。安装完成后，扩展会出现在列表中。

### 开始使用

1. 打开学习通课程，按页面提示用学习通 APP 扫码登录，然后进入要学习的章节详情页。
2. 在课程页面右下角找到“课程顺序播放助手”。选择“测验处理”方式，再点击“开始”。首次使用可保持默认的“自动跳过测验”，无需填写 API Key。
3. 保持这个课程标签页打开。需要停止时点击“暂停”；助手自行暂停时，按面板提示处理。课程结束后，到学习通页面核对实际完成情况。

“测验处理”可以选择：自动跳过（测验仍未完成）、遇到测验暂停、由模型填写后自己确认提交，或由模型填写并自动提交。后两项需要先完成下方设置。

### 如果要使用模型答题

点击助手中的“设置”，选择“DeepSeek 官方”或自己的接口服务，填写模型名称和 API Key（从所用服务商获取）。Base URL 是接口地址；选用 DeepSeek 官方时，默认地址为 `https://api.deepseek.com`。点击“保存并测试连接”，确认连接成功后，回到课程页选择一种“自动填写”方式。测试连接会调用一次 API，可能产生费用。

如果选择“自动填写，手动确认”，请先检查答案，再点击“确认提交并继续”。更新扩展后，需要在扩展管理页点击“重新加载”，再刷新原课程页。遇到错误时，可在“设置”中导出诊断日志。
