# 学习通课程顺序播放助手

本程序是本地 Edge/Chrome 扩展，无需下载第三方库。使用者在学习通页面自行扫码登录，然后在章节详情页点击右下角的“开始”。程序从当前内容出发，按页面“下一节”的顺序处理视频和 PDF 文档。

## 页面分析依据

- REA 在隔离浏览器中访问课程链接时，确认未登录会跳转到学习通登录页（证据 ID：`ev_a5adcd30b89dd8674d636d4b24b6667f5f10835203fd344c5d05c5d19631236a`）。隔离浏览器没有使用者的登录状态，因此该条证据只覆盖登录跳转。
- 在使用者已登录的浏览器页面中，课程显示“已完成任务点 7/160”。1.2 节包含一个已完成的 PDF 课件任务和三个未完成的视频任务；页面明确写明视频完成条件为观看时长至少达到总时长的 90%，且未完成前不能拖拽。
- 章节详情页通过 `#iframe` 加载卡片，视频任务在 `.videoContainer` 中，完成状态由 `.ans-job-finished` 和任务点图标表示；页面通过“下一节”按钮推进。程序只根据这些可见页面状态工作。
- 有些 PDF 仅是课件内容，没有任务点图标；程序不会把这类内容误认为待完成任务点。
- 没有分析或调用学习进度的服务端接口，因此无法保证所有章节的任务类型都相同，也无法从客户端保证平台最终判定为完成。
- 2026-10-17 通过 REA 被动连接现有 Edge 课程标签页并采集脚本，证据 ID：`ev_377946760c325f9b325caec25074d5643af92e51bf32712e33a4bf5823f851fe`。从 `videojs-ext.min.js` 的字符串表还原出 `studyControl`：它在顶层窗口监听冒泡的 `mouseout`，当 `relatedTarget/toElement` 为空且 `enableSwitchWindow !== 1` 时调用播放器 `pause()`。这确认了鼠标离开页面可能触发暂停的代码路径；尚未验证后台任务点计入结果。

## 安装与使用

1. 在 Edge 打开 `edge://extensions`，开启“开发人员模式”，点击“加载解压缩的扩展”，选择本项目的 `extension` 文件夹。Chrome 的入口是 `chrome://extensions`。
   更新扩展后还需刷新已打开的课程页面；旧页面中的脚本无法在扩展重新加载后继续使用。
2. 自行通过学习通 APP 扫码登录。扩展不读取、保存或传输密码和登录凭据。
3. 打开目标课程中第一个未完成的章节详情页，点击右下角“开始”。请保持该标签页打开，并允许正常播放声音。
   同一时间只在一个标签页运行；若在另一个标签页启动，原标签页会暂停。
4. 若遇到验证码、风控提示、登录失效、未知任务类型、播放停滞或完成状态迟迟不更新，程序会暂停。处理原因后再次点击“开始”。
5. 面板和 API 设置页的“测验处理”提供四个互斥选项：“自动跳过测验”（默认）、“遇到测验暂停”“自动填写，手动确认”“自动填写，自动提交”。跳过时若出现“当前章节还有任务点未完成，是否去完成？”弹窗，助手会点击弹窗内的“下一节”，保留测验未完成状态。

## 大模型答题（0.4.0）

1. 点击面板“API 设置”，选择 DeepSeek 官方或自定义 OpenAI 兼容服务。填写 Base URL、模型 ID 和 API Key；官方默认地址为 `https://api.deepseek.com`，模型 ID 由用户填写。
2. 保存时仅申请所配置 API 域名的访问权限。密钥默认保留到浏览器会话结束；可选择保存到本机。扩展存储并非加密保险箱，密钥不进入页面脚本、日志或代码仓库。
3. 点击“保存并测试连接”会产生一次实际 API 请求，检查认证与结构化输出。默认启用 JSON 输出；其他兼容服务不支持时可关闭，但答案仍必须通过本地 JSON 校验。
4. 在原课程页暂停助手，点击“检查测验结构”。此操作只读取题目数量、题型和提交控件，不调用模型、不填写或提交。
5. 选择自动填写模式并点击“开始”。题目按最多 10 题及文本长度分批串行发送，仅包括题型、题干、选项和临时 ID，不发送登录凭据或课程 URL。无需参考资料。
6. “手动确认”模式填完后显示“确认提交并继续”；“自动提交”模式通过全部校验后直接提交。已有不同作答、缺题、无效选项或未识别题型会暂停，不覆盖手工作答。
7. 提交状态保存在当前标签页；刷新后若上次提交结果不明，会暂停核对而不重复交卷。更换题目后旧缓存失效；页面明确确认任务点完成后继续课程。

当前适配基于 REA 采集的章节测验（48 题，36 单选、12 多选）脚本：`doHomeWorkNew` 的 `.TiMu`、`qid/qtype` 选项控件、`answer` 字段，以及顶层 `workpop` 交卷确认。判断题按相同控件协议处理；题目数量不全、分页结构不同或含图片／公式／媒体时会暂停。模型请求超时、后台中断可以保留已校验的批次，重新开始后继续；不保证模型答案正确。

## 运行规则

- 视频优先使用播放器菜单中的 2 倍速；如果没有该选项、选项被禁用或播放器未接受设置，就使用 1 倍速。从当前进度播放到结束，并等待页面显示任务点完成后前进。不拖拽，不发送学习记录请求。
- 视频出现单选题或多选题时，一次只按正常界面提交一个候选答案。提交约 0.5 秒后，若题目仍在且视频没有恢复，就将本次尝试视为失败；若仍可直接提交，尝试下一组，相邻提交至少间隔 0.5 秒（浏览器调度可能使实际间隔更长）；若平台回退进度，则从回退处继续播放，重新遇到题目后再尝试下一组。所有候选组合都失败时暂停并提示手动处理。题目状态和尝试位置保存在当前标签页中，关闭标签页后会重置。
- 已显示完成的任务点直接略过。PDF 文档打开后，将其内部可滚动阅读区域滚至底部；每轮检查延迟加载后增加的高度，支持可访问的嵌套阅读器。仅在页面显示任务点完成后继续；90 秒内未确认就暂停，不臆断已完成。跨域或浏览器内置阅读器无法访问时，需要手动阅读。
- 只使用课程页面自身的“下一节”操作。到达末节后暂停并提示核对课程总进度。
- 助手运行且视频正在播放时，在文档层阻止“鼠标离开页面”的 `mouseout` 继续冒泡到顶层窗口，针对上述 `studyControl` 暂停路径提供保护。页面内部鼠标移动不受影响；停止助手、视频已暂停或检测到验证提示时不拦截。不伪造可见性或焦点。
- 0.4.2：视频曾正常播放、页面处于后台或失焦时，如果发生意外暂停且没有题目、弹窗、验证或媒体错误，则通过播放器正常 `play()` 尝试续播，每个视频在一次运行中最多两次。页面播放器上的手动暂停、前台暂停及播放被浏览器拒绝时仍停止；不会无限重试。浏览器休眠或系统睡眠期间无法保证运行。
- 读取助手运行状态和设置时，遇到后台消息通道暂时中断会有限重试两次；不重试模型请求或写操作。最近一次主动停止的原因保存在当前标签页，刷新后显示，便于排查。
- 视频内题目仅处理一道单选或多选；超过 5 个选项、包含多个小题或无法继续提交时会暂停。独立章节测验按配置跳过、暂停或由模型答题；同页视频、文档仍依次处理，其他未知任务仍暂停。考试和身份验证不在支持范围内。

## 已知限制

目前根据课程 1.2 节页面结构实现：该节的 PDF 已显示完成，三个视频任务均要求观看时长至少达到 90%，未完成前不可拖拽。另检查了示例物理课程的视频题目，确认单选／多选界面具有选项、提交、回答反馈和继续按钮。其他章节若出现不同类型的文档、交互任务或弹窗，会安全暂停，需要进一步适配。浏览器可能阻止后续视频自动播放；出现提示时需使用者手动启动当前视频。有的课程明确要求播放时不能离开或最小化页面，使用时应保持课程标签页处于前台。

课程完成由平台判定。扩展不会因“已到最后一节”就声称全部任务点完成，请最终核对课程页的已完成任务点数量。

## 诊断日志（0.4.4）

面板“设置”中可以导出和清理日志。日志持久保存在本机 `chrome.storage.local`，保留最近 500 条；不会自动写入独立磁盘文件，导出时生成 JSON 文件。卸载扩展或清除扩展数据会删除日志。

记录模型请求批次题数、尝试次数、HTTP 错误、输出结束状态和长度、校验失败原因、助手暂停原因，不保存 API Key、课程地址、完整题目、模型原文或推理内容。日志从更新后开始记录，无法恢复此前失败响应。

校验错误现在保留具体原因，并在一次修复请求中告诉模型失败原因；兼容完整 JSON 代码围栏，仍严格检查题目和选项 ID。输出被截断会明确提示，不接受不完整答案。

### 0.4.5：输出截断恢复

DeepSeek 官方接口返回 `finish_reason=length` 后，下一次请求通过 `thinking.type=disabled` 关闭思考模式，保留原模型名称和输出预算；只切换一次，仍截断则暂停。自定义兼容接口不发送此专有参数，截断后直接报告原因，避免原样重试。日志新增推理文本长度和输出 token 数，不保存推理文本。关闭思考模式可能影响答题准确率，输出仍须通过原有结构校验。

### 0.4.6：视频进度停滞恢复

当播放器仍报告播放中但超过 90 秒没有进度时，若没有题目、弹窗、验证或媒体错误，助手尝试一次暂停后原速续播，不跳进度、不刷新页面。续播等待最多 12 秒；仍停滞 90 秒或续播失败则停止。每个视频在本次运行中仅恢复一次。

日志新增停滞时的 currentTime、readyState、networkState、媒体错误码、页面隐藏状态及是否尝试过恢复。2026-10-18 在现有 Edge 标签页观察到视频停在 0:12；当前采集无法还原此前的网络或后台调度情况，因此未将原因认定为浏览器休眠。

### 0.4.7：完成标记兼容

任务完成识别兼容课件 iframe 的直接父节点、任务图标父节点上的完成 class，以及任务图标的“任务点已完成”文字。结束检查复用相同判断，避免滞后的 aria-label 再次阻止前进。仅检查当前附件内的标记，不以文档滚到底作为完成依据。
