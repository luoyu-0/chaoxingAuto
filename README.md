# 学习通课程顺序播放助手

当前版本：**0.4.8**。本项目是适用于 Edge 和 Chrome 的本地浏览器扩展。

## 产品介绍

助手从当前章节开始，按课程页面顺序处理视频和 PDF 文档，并根据平台显示的任务点状态进入下一项。视频优先尝试 2 倍速，不允许时使用原速；文档会滚动可访问的阅读区域，并等待平台确认完成。助手不会拖动视频进度或自行发送学习记录。

章节测验可选择自动跳过、遇到时暂停、使用模型填写后手动确认，或使用模型填写并自动提交。视频中途出现的单选题或多选题会逐组尝试；无法继续时暂停，提示使用者处理。模型答题支持 DeepSeek 官方 API 和自定义 OpenAI 兼容接口。

扩展在本机运行，使用者自行通过学习通 APP 扫码登录。设置页支持导出和清理本机诊断日志。

## 使用方式

1. 在 Edge 打开 `edge://extensions`（Chrome 使用 `chrome://extensions`），开启“开发人员模式”，点击“加载解压缩的扩展”，选择本项目的 `extension` 文件夹。
2. 自行扫码登录学习通，打开课程章节详情页，在右下角助手面板选择“测验处理”模式并点击“开始”。同一时间只在一个课程标签页运行。
3. 如需模型答题，点击“设置”，填写 Base URL、模型 ID 和 API Key。DeepSeek 官方默认地址为 `https://api.deepseek.com`；可先用“保存并测试连接”检查配置。该测试会产生一次实际 API 请求。
4. 选择“自动填写，手动确认”时，核对答案后点击“确认提交并继续”。需要排查测验页面时，先暂停助手，再点击“检查测验结构”。
5. 按面板提示处理需要人工介入的情况。更新扩展后，重新加载扩展并刷新原课程标签页。课程结束后，到平台页面核对最终进度。

“测验处理”有以下四种互斥选项，默认选择“自动跳过测验”：

| 模式 | 行为 |
| --- | --- |
| 自动跳过测验 | 保留测验未完成状态，进入下一项。 |
| 遇到测验暂停 | 停下等待使用者处理。 |
| 自动填写，手动确认 | 模型填写答案，使用者确认后提交。 |
| 自动填写，自动提交 | 模型填写并校验答案后提交。 |

请保持课程标签页打开，并允许视频正常播放声音。助手遇到未识别任务、验证码、登录失效或平台风险提示时会停止。文档已滚动到底但尚未获得平台完成标记时会继续等待，可手动暂停。诊断日志可在“设置”页导出为 JSON 文件。
