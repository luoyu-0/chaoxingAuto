# 学习通课程顺序播放助手

本程序是本地 Edge/Chrome 扩展，无需下载第三方库。使用者在学习通页面自行扫码登录，然后在章节详情页点击右下角的“开始”。程序从当前内容出发，按页面“下一节”的顺序处理视频和 PDF 文档。

## 页面分析依据

- REA 在隔离浏览器中访问课程链接时，确认未登录会跳转到学习通登录页（证据 ID：`ev_a5adcd30b89dd8674d636d4b24b6667f5f10835203fd344c5d05c5d19631236a`）。隔离浏览器没有使用者的登录状态，因此该条证据只覆盖登录跳转。
- 在使用者已登录的浏览器页面中，课程显示“已完成任务点 7/160”。1.2 节包含一个已完成的 PDF 课件任务和三个未完成的视频任务；页面明确写明视频完成条件为观看时长至少达到总时长的 90%，且未完成前不能拖拽。
- 章节详情页通过 `#iframe` 加载卡片，视频任务在 `.videoContainer` 中，完成状态由 `.ans-job-finished` 和任务点图标表示；页面通过“下一节”按钮推进。程序只根据这些可见页面状态工作。
- 有些 PDF 仅是课件内容，没有任务点图标；程序不会把这类内容误认为待完成任务点。
- 没有分析或调用学习进度的服务端接口，因此无法保证所有章节的任务类型都相同，也无法从客户端保证平台最终判定为完成。
- 2026-10-17 通过 REA 被动连接现有 Edge 课程标签页并采集脚本，证据 ID：`ev_377946760c325f9b325caec25074d5643af92e51bf32712e33a4bf5823f851fe`。从 `videojs-ext.min.js` 的字符串表还原出 `studyControl`：它在顶层窗口监听冒泡的 `mouseout`，当 `relatedTarget/toElement` 为空且 `enableSwitchWindow !== 1` 时调用播放器 `pause()`。这确认了鼠标离开页面可能触发暂停的代码路径；尚未验证后台任务点计入结果。

## 安装与使用

1. 在 Edge 打开 `edge://extensions`，开启“开发人员模式”，点击“加载解压缩的扩展”，选择本项目的 `extension` 文件夹。Chrome 的入口是 `chrome://extensions`。
   更新扩展后还需刷新已打开的课程页面；旧页面中的脚本无法在扩展重新加载后继续使用。
2. 自行通过学习通 APP 扫码登录。扩展不读取、保存或传输密码和登录凭据。
3. 打开目标课程中第一个未完成的章节详情页，点击右下角“开始”。请保持该标签页打开，并允许正常播放声音。
   同一时间只在一个标签页运行；若在另一个标签页启动，原标签页会暂停。
4. 若遇到验证码、风控提示、登录失效、未知任务类型、播放停滞或完成状态迟迟不更新，程序会暂停。处理原因后再次点击“开始”。
5. 面板中的“自动跳过测验”默认开启，设置在当前标签页刷新后保留；关闭后遇到章节测验会暂停等待手动处理。“使用大模型自动答题”为禁用的预留开关，尚未实现，不会发送模型请求。跳过时若出现“当前章节还有任务点未完成，是否去完成？”弹窗，助手会点击弹窗内的“下一节”，保留测验未完成状态。

## 运行规则

- 视频优先使用播放器菜单中的 2 倍速；如果没有该选项、选项被禁用或播放器未接受设置，就使用 1 倍速。从当前进度播放到结束，并等待页面显示任务点完成后前进。不拖拽，不发送学习记录请求。
- 视频出现单选题或多选题时，一次只按正常界面提交一个候选答案。提交约 0.5 秒后，若题目仍在且视频没有恢复，就将本次尝试视为失败；若仍可直接提交，尝试下一组，相邻提交至少间隔 0.5 秒（浏览器调度可能使实际间隔更长）；若平台回退进度，则从回退处继续播放，重新遇到题目后再尝试下一组。所有候选组合都失败时暂停并提示手动处理。题目状态和尝试位置保存在当前标签页中，关闭标签页后会重置。
- 已显示完成的任务点直接略过。PDF 文档打开后，将其内部可滚动阅读区域滚至底部；每轮检查延迟加载后增加的高度，支持可访问的嵌套阅读器。仅在页面显示任务点完成后继续；90 秒内未确认就暂停，不臆断已完成。跨域或浏览器内置阅读器无法访问时，需要手动阅读。
- 只使用课程页面自身的“下一节”操作。到达末节后暂停并提示核对课程总进度。
- 助手运行且视频正在播放时，在文档层阻止“鼠标离开页面”的 `mouseout` 继续冒泡到顶层窗口，针对上述 `studyControl` 暂停路径提供保护。页面内部鼠标移动不受影响；停止助手、视频已暂停或检测到验证提示时不拦截。不伪造可见性或焦点，不强制恢复其他原因造成的暂停。
- 仅处理视频内的一道单选题或多选题；题目超过 5 个选项、包含多个小题或无法继续提交时会暂停。独立章节测试根据作业 iframe 类型或地址识别并跳过，保留未完成状态；同页视频、文档仍依次处理，其他未知任务仍暂停。章节测试需之后手动完成，程序不提交章节作业、考试或身份验证。

## 已知限制

目前根据课程 1.2 节页面结构实现：该节的 PDF 已显示完成，三个视频任务均要求观看时长至少达到 90%，未完成前不可拖拽。另检查了示例物理课程的视频题目，确认单选／多选界面具有选项、提交、回答反馈和继续按钮。其他章节若出现不同类型的文档、交互任务或弹窗，会安全暂停，需要进一步适配。浏览器可能阻止后续视频自动播放；出现提示时需使用者手动启动当前视频。有的课程明确要求播放时不能离开或最小化页面，使用时应保持课程标签页处于前台。

课程完成由平台判定。扩展不会因“已到最后一节”就声称全部任务点完成，请最终核对课程页的已完成任务点数量。
